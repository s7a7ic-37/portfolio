Contract Check

Compare a JSON response with a small shape contract. Catch missing fields and type changes before they reach the next part of an app.

Runs in your browserNo uploadJSON

Check a response

Use type names such as "string" and "number", nested objects, or a one-item array template. Extra response fields are allowed.

All listed fields are required. An empty object means “must be an object”.

    The contract format is intentionally small for learning and quick checks; it is not a full JSON Schema implementation.
